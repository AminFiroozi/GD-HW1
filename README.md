# GD-HW1 — Endless Runner

A Chrome-Dino-style endless runner built in Unity for the Computer Game Design course.

![Gameplay](Screenshots/gameplay.png)

## Gameplay

Run across the desert, jump and duck past obstacles, collect coins, and survive as long as you can while the pace keeps ramping up.

## Controls

| Action | Key |
|---|---|
| Jump | Space (hold longer for a higher jump, release early to cut it short) |
| Duck / Dash | Shift (speeds up and ducks while held; tap again mid-air to fast-fall) |
| Pause | Esc |

## Features

- Procedural obstacle spawning (ground cacti, flying bats, coins) with difficulty ramping over distance
- Variable jump height (jump-cut) and mid-air dash fast-fall
- Dash speeds up both movement and the run animation together
- Full death sequence on game over, followed by a short delay before the restart screen
- Decorative background scattering (cacti, sand patches, clouds) for a livelier desert scene, fully independent of gameplay spawning
- High score tracking across runs
